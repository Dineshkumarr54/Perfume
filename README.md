# Perfume Landing Page 🌸

This is a simple and elegant perfume landing page built using HTML and CSS. The design showcases a fictional perfume brand with a stylish layout, product listings, and basic company information.

## 🔍 Features

- Responsive layout
- Navigation bar with Home, Products, About, and Contact links
- Search bar
- Product section with images and descriptions
- About and Contact sections

## 💻 Technologies Used

- HTML5
- CSS3
